# /chip:finish — закрыть сессию в проекте Чипа

То же, что промпт `finish` MCP-сервера, командой плагина.

## Что сделать

Определи `project_id` (из `.chip.json` в корне репозитория, иначе спроси). Затем
четыре записи, каждая своим инструментом:

1. `mcp__chip__save_session_summary(project_id, text)` — ОДНА сводка по
   структуре **Сделано → Решения и почему (включая отвергнутые) → Грабли →
   Осталось**. Одна, не дроби на несколько.

2. Каждое решение продублируй `mcp__chip__add_note(project_id, …,
   kind="decision")` формулой «что решали → выбрали X вместо Y, потому что Z».
   Без «почему» следующая сессия переспорит то же самое.

3. Каждую граблю — `mcp__chip__add_note(project_id, …, kind="pitfall")`:
   симптом → причина → лечение.

4. Каждый пункт «Осталось» — `mcp__chip__add_task(project_id, …)`: следующая
   сессия увидит его в `list_tasks`.

## Границы

- Пиши на языке пользователя.
- Записывать нечего (сессия была разговором, а не работой) — так и скажи.
  Пустую сводку не сочиняй: журнал проекта дороже галочки.
- Сводка одна на сессию. У сводок свой дневной кап, отдельный от лимита записей и
  заметно меньше его (остаток показывает `whoami`): раздробил дневную сводку на
  три — вечерняя уже не влезет. «Лимит записей» — это про `add_note`.
